# Neon District — Mobile Open-World Action Game

An original mobile-first open-world action game prototype inspired by the freedom and systemic gameplay of modern open-world games.

## Project direction
- Platform: Android / iOS
- Engine target: Unity
- Camera: third-person
- Core loop: explore, drive, complete missions, interact with NPCs, and upgrade the player
- Art direction: stylized realistic urban sandbox
- All characters, locations, missions, UI, and assets should be original.

## Prototype roadmap

### Phase 1 — Playable vertical slice
1. Third-person player movement
2. Touch joystick + action buttons
3. Small streaming city block
4. Enter/exit vehicle
5. Basic vehicle driving
6. NPC pedestrian navigation
7. Wanted/alert system
8. Mission marker and objective system
9. Save/load
10. Android performance settings

### Phase 2 — Open-world systems
- Larger streamed map
- Traffic system
- Shops and interiors
- Day/night cycle
- Police AI
- Economy and vehicle garage
- Mission chains
- World events

### Phase 3 — Polish
- LOD and occlusion
- Addressables/asset streaming
- Mobile GPU/CPU profiling
- Haptics and controller support
- Audio pass
- Accessibility and settings

## Repository structure

`docs/` contains design notes and technical decisions.
`prototype/` contains engine-agnostic gameplay prototypes.
`unity/` is reserved for the Unity project.
`tools/` contains small development utilities.
